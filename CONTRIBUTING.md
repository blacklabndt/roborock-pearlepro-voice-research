# Contributing evidence

Please use GitHub issues or pull requests for reproducible findings, corrections and public documentation.

Include model, package voice ID/version, official source URL, SHA-256, analysis tool/version and exact observations. Separate observed bytes, interpretation and untested hypotheses. Use synthetic fixtures when possible; do not redistribute proprietary apps, plugins or voice recordings without permission.

Do not upload account credentials, tokens, verification codes, private logs, local network details, serial numbers, device IDs or protected cryptographic secrets. Please keep contributions focused on offline interoperability and format documentation; do not submit exploitation, key-extraction or signature-bypass workflows.

Useful contributions include independent checks of the trailer relationships, documented format references, explanations of the catalog checksum discrepancy and audio metadata from an authorized plaintext source. No installer or custom firmware is provided here.
